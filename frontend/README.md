# Zomato Reels - Frontend

React + Vite frontend for the Zomato Reels application.

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Dev Server
```bash
npm run dev
```
The app will be available at `http://localhost:5173` (or the port shown in your terminal).

### Production Build
```bash
npm run build
```
Build output is generated into the `dist/` directory.
